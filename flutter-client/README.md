## Структура проекта

```text
lib/
├── core/          # Базовые компоненты (сеть, роутинг, хранилище, тема)
├── data/          # Слой данных (модели, API-клиенты, репозитории)
├── domain/        # Бизнес-логика (интерфейсы репозиториев)
└── features/      # Функциональные модули (auth, projects, и т.д.)
```

## Технологии

- **Flutter** — кроссплатформенный UI-фреймворк
- **Riverpod** — управление состоянием
- **GoRouter** — маршрутизация
- **Dio** — HTTP-клиент
- **SharedPreferences** — хранение токена
